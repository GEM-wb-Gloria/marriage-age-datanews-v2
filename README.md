## ✨ V2.0 先锋杂志级视觉与交互亮点

1. **物化叙事隐喻：《当代青年城市成家成本热敏小票》**
   - 首屏打破传统仪表盘布局，将上海 0-17 岁养育成本（`¥1,010,130`）、深圳房价收入比（`34.8倍`）、一线城市青年整租负担比（`24.5%–27.0%`）、企业周均工时（`49.0h`）及女性因家务脱离职场比例（`13.0% vs 2.9%`，4.5倍差距）设计为一张微倾 `2.5°`、带锯齿撕纸边缘与条形码的**热敏结账单**，叠放在暗红色《结婚登记档案（囍）》之上，并加盖**朱砂核验方印**。
2. **手绘墨迹圈注与倾斜跑马灯数据胶带（Kinetic Ticker Tape）**
   - 主标题采用随滚动自动落笔的 SVG 朱砂红手绘圈注线与青色波浪下划线；首屏下方嵌入 `-1.1°` 斜向贯穿视口的跑马灯数据胶带，搭配全屏暗黑胶片颗粒噪点层（`.film-grain`）与巨幅空心视差背景大字。
3. **原创交互标尺：《2010 vs 2024 青春时差尺》**
   - 选取 `24.00岁` $\rightarrow$ `24.89岁` $\rightarrow$ `26.97岁` $\rightarrow$ `27.95岁` $\rightarrow$ `29.50岁` $\rightarrow$ `30.80岁` 六个人口学关键节点，跨代际并置对比 2010 年六普同龄人的婚育常态与 2024 年同龄城市青年的生存切面。
4. **“白省蓝海”31省婚育图鉴 + 动态朱砂省印**
   - 纯白省域（`#ffffff`）+ 深海蓝底（`#0c4a6e → #072a47`）高定地图画布，四角镶嵌测绘十字准星与航海罗盘。点击任意省份或直辖市，实时联动该省**女性平均初婚年龄**、**粗结婚率（‰）**与**结婚登记人口**，并动态加盖专属**朱砂省印**（如 `[粤 · 结婚人口 NO.1]`、`[黑 · 31.48岁全国最晚婚]`、`[沪 · 30.1岁晚婚极值]`）。
