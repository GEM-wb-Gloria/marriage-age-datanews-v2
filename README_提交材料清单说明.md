## 一、 快速使用与评审指南

1. **查阅核心交互作品**：
   - 直接双击打开 `01_作品正文/index.html`。
   - 该网页为自包含式先锋交互长图，内置 TailwindCSS、ECharts、Lucide 图标库与高精度中国矢量地图，支持离线或在线环境流畅运行，具备极佳的响应式适配。
   - 交互亮点：支持青春生命时差尺刻度点选、31省市白省蓝海地图档案穿透、城市居住养育多维气泡矩阵探索、工时与母职惩罚双轴联动，以及第六章宏观双维深度解码台。
2. **核验数据真实性与权威信源**：
   - 详见 `02_数据文件/数据信源与统计口径说明书.md`。全项目所有数据 100% 具备权威统计机构与顶级高校实证智库出处，零虚构、零插值。
3. **复现数据清洗与统计检验**：
   - 在终端进入 `03_分析代码/`，运行 `python3 data_cleaning_and_analysis.py` 即可在本地秒级复现全部计算结果、回归拟合线参数及统计报告。
